## DR-001: SSoT = GitHub + локальный _MEMORY/
- **Дата:** 2026-09-02
- **Контекст:** Выбор главного источника истины для системы общей памяти агентов
- **Варианты рассмотрены:** Google Drive (только), GitHub (только), локальный JSON, гибридная схема
- **Решение:** Гибрид: локальный `_MEMORY/` (primary) + GitHub (backup + versioning) + Drive (mirror для NotebookLM)
- **Причина:** При отключении света в Одессе локальный файл сохранён на диске. GitHub хранит полную историю. Drive служит readable зеркалом.

## DR-002: Только Agent 5 (Spark) пишет в MEMORY.json
- **Дата:** 2026-09-02
- **Контекст:** Предотвращение конфликтов записи при параллельном запуске агентов
- **Решение:** Агенты 1-4 пишут в `_MEMORY/agent_N_output.json`. Agent 5 читает их и консолидирует в `MEMORY.json`.
- **Причина:** Без file locking несколько агентов могут одновременно записать в MEMORY.json и создать некорректный JSON.

## DR-003: Drive Converter — polling 30 сек вместо Pub/Sub
- **Дата:** 2026-09-01
- **Контекст:** Выбор механизма триггера обработки новых файлов в 01_INBOX
- **Варианты:** Google Pub/Sub (нужен отдельный GCP проект), Drive Notifications (нужен HTTPS webhook endpoint), Polling
- **Решение:** Polling каждые 30 секунд с exponential backoff при сетевых ошибках
- **Причина:** Polling работает без публичного HTTPS-эндпоинта и дополнительных GCP сервисов. Достаточно для объёма обработки.

## DR-004: service_account.json — не в GitHub (.gitignore)
- **Дата:** 2026-09-01
- **Контекст:** Безопасное хранение GCP credentials
- **Решение:** `service_account.json` добавлен в `.gitignore`. Для Railway — переменная `GCP_SERVICE_ACCOUNT_JSON`. Для Recovery — из Google Cloud Console (IAM → Service Accounts → Keys).
- **ВАЖНО:** Никогда не коммитить этот файл в git!

## DR-005: NotebookLM — полуавтоматическая схема
- **Дата:** 2026-09-02
- **Контекст:** Интеграция с NotebookLM для RAG-поиска по проектным материалам
- **Решение:** Drive Converter автоматически конвертирует файлы из 01_INBOX в MD → кладёт в 02_FOR_NOTEBOOK. Пользователь один раз вручную добавляет эту папку как источник в NotebookLM UI.
- **Причина:** NotebookLM не имеет публичного API для программной загрузки источников (по состоянию на сентябрь 2026).
